🛒 Online Shopping Database

📌 Project Overview

The Online Shopping Database is a MySQL-based database management system designed to manage the core operations of an online shopping platform.

It stores and manages information related to customers, products, orders, payments, and inventory, while demonstrating database design, relationships, and SQL queries.

🛠️ Technologies Used

- Database: MySQL
- Language: SQL
- Tool: MySQL Workbench

🗄️ Main Features

- 👤 Customer management
- 🛍️ Product management
- 📦 Order management
- 💳 Payment management
- 🏪 Inventory management
- 🔗 Relationships between database tables
- 🔍 SQL queries for retrieving and managing data

📊 Database Operations

The project demonstrates:

- Creating databases and tables
- Primary and foreign keys
- Table relationships
- "INSERT", "UPDATE", and "DELETE"
- "SELECT" queries
- "JOIN" operations
- Filtering and sorting data
- Aggregate functions
- Data management using SQL

🎯 Objective

The main objective of this project is to design and implement a structured MySQL database for an online shopping system and demonstrate practical knowledge of relational databases and SQL.
